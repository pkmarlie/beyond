# Security

This repository contains a static website.

## Reporting a vulnerability

Do not post sensitive security details in a public issue.

Report suspected vulnerabilities privately to the repository owner through an appropriate GitHub private/security reporting channel available for this repository. Include:

- A clear description of the issue
- Steps to reproduce it
- The affected file or component
- Any relevant screenshots or proof of concept

Please avoid including passwords, private tokens, or other secrets in reports.

## Secrets

Do not commit:

- API keys
- Access tokens
- Passwords
- Private credentials
- Unnecessary personal or customer data

The public website source should contain only information intended to be published.
