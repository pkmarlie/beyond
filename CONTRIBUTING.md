# Contributing

Thanks for helping improve the Beyondbooks site.

## Before making changes

- Keep the project lightweight and dependency-free where practical.
- Preserve the Hindi-first experience unless a change intentionally modifies it.
- Keep mobile layouts usable.
- Maintain accessible focus states and button labels.
- Respect the existing WhatsApp and Google Maps links unless they are being intentionally updated.

## Making an edit

For a content-only change, edit the relevant text in `index.html`.

For styling or behavior changes:

1. Make the smallest change that solves the problem.
2. Check the page in a desktop viewport.
3. Check the page in a narrow/mobile viewport.
4. Test the Hindi/English toggle.
5. Test the review carousel controls and mobile swipe behavior.
6. Verify the main WhatsApp CTA links still work.

## Commit messages

Use clear, action-oriented commit messages, for example:

- `Update trial CTA copy`
- `Fix mobile header spacing`
- `Update Beyondbooks address`
